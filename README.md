# 新纪元设计大赛 2026 · 小程序方案原型

斯芬克「东方新语，潮启未来」2026 年度赛事（米兰设计周独立命题赛道）小程序活动页的方案原型。
在去年活动页结构的基础上，新增「去年回顾」「校企合作」两个模块，并针对 6 个模块的导航排布给出 5 套方案。

- 单文件版（全部方案打包，可直接发给别人）：https://1296657718-star.github.io/sfk-milan-design/compare.html

## 视觉与内容说明

- 视觉：2026 策划案「墨绿 + 金」主题（主墨绿 `#1B382E` / 亮档 `#265045` / 深档 `#10241C`，金色系保留）。去年页面为红金，基础还原稿保留红金原貌。
- Hero：对齐 PPT 封面的海报式排版——金色 kicker + 短金线、宋体金色大标语「东方新语，潮启未来」+ 英文副题、金框 10th 徽章。
- 校企合作页：企业命题矩阵（恒源祥 / 莲香楼 / 福建头部茶企）、合作模式旅程图、双导师体系、成果落地通路、评价标准 CRAFT 全球胜任力模型。
- 去年回顾页：往届现场 4 图 + 往届优秀作品 2 图（图片已内嵌，单文件不依赖外部资源）。

## 技术说明

- 每套方案为一个独立 HTML 单文件，样式与交互内联，图片 base64 内嵌，可直接单发。
- 手机框按 iPhone 15/16 Pro 逻辑分辨率 393×852 还原，内部独立滚动。
- 生成方式：`gen_tab_variants.py` 从基础还原稿派生 5 套方案，`build_portable.py` 打包为 srcdoc 内联的单文件版。
